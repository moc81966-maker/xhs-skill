## 三、命令详解 — 内容生成类

### 命令 1：`/xhs plan`

**用途：** 生成完整的内容计划

**格式：**
```
/xhs plan [赛道] [天数] [--series 系列名]
```

**参数：**

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| 赛道 | 否 | 内容方向 | 知识干货 |
| 天数 | 否 | 计划天数 | 7 |
| --series | 否 | 系列化名称 | 无 |

**示例：**
```
/xhs plan 知识干货 7
/xhs plan 生活方式 14
/xhs plan 知识干货 30 --series "AI工具30天挑战"
```

**输出内容（每天）：**
- 📌 主题定位
- 🎯 5个标题备选 + 最终推荐
- 🎨 封面设计建议
- 📝 完整正文（300-500字）
- ⏰ 最佳发布时间
- 🏷️ 5-8个话题标签
- 📣 发布后操作建议
- 🔗 系列化关联（如有）

**额外输出：**
- 账号基础设置指南
- 养号方法（3-5天）
- 每日运营 Checklist
- 数据追踪表模板
- 爆款要素 Checklist

### 命令 2：`/xhs post`

**用途：** 生成单篇完整的小红书笔记

```

**参数：**

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| 主题 | 是 | 笔记主题 | — |
| --all | 否 | 一鱼多吃模式 | 否 |
| --style | 否 | 风格（口语/专业/搞笑/文艺） | 口语 |

**示例：**
```

/xhs post 打工人副业赚钱 --style 口语
/xhs post AI学英语 --all
```

**`--all` 模式输出：**
同时生成以下4个版本：
1. 小红书图文版
2. 视频脚本版
3. 朋友圈文案版
4. 公众号文章框架版

### 命令 5：`/xhs video`

**用途：** 生成小红书视频脚本

**格式：**
```
/xhs video [主题] [--duration 时长]
```

**参数：**

| 参数 | 必填 | 说明 | 默认值 |
|------|------|------|--------|
| 主题 | 是 | 视频主题 | — |
| --duration | 否 | 时长（30/60/120/180秒） | 60 |

**示例：**
```
/xhs video AI做PPT
/xhs video 学英语 --duration 120
```

**脚本结构：**
```
├── Hook（0-3秒）— 抓住注意力的开头
├── 痛点（3-10秒）— 引起共鸣
├── 内容（10-50秒）— 核心干货
│   ├── 要点1
│   ├── 要点2
│   └── 要点3
├── 总结（50-55秒）— 回顾重点
└── CTA（55-60秒）— 引导关注/收藏
```

**额外输出：**
- 分镜建议（每个镜头的画面描述）
- 配音文案（可直接朗读）
- 字幕文案
- BGM建议
- 封面建议

## 八、内置知识库

### 爆款公式

```
标题 = 数字 + 痛点 + 解决方案
内容 = 痛点引入 + 解决方案 + 具体步骤 + 互动引导
涨粉 = 日更 + 蹭热点 + 互动引流 + 系列化内容
视频 = Hook(3秒) + 痛点(7秒) + 内容(40秒) + CTA(10秒)
```

### 发布时间

| 时段 | 工作日 | 周末 |
|------|--------|------|
| 早 | 7:00-9:00 | 10:00-11:00 |
| 中 | 12:00-14:00 | — |
| 晚 | 18:00-22:00 | 19:00-20:00 |

**最佳：** 周三/周五晚上

### 标签策略

```
2个大流量标签（#AI #效率提升）
3个中流量标签（#打工人 #办公技巧）
2个精准标签（#Gamma #PPT教程）
```

### 养号方法

```
每天操作（3-5天）：
- 刷小红书 30 分钟以上
- 搜索相关关键词
- 给同类博主点赞 15-20 条
- 评论同类博主 5-10 条（真诚评论）
- 收藏优质内容 10 条以上
- 关注 20-30 个同领域博主
```

### SEO原则

```
标题必须包含核心关键词
正文前100字包含核心关键词
标签覆盖核心词+长尾词
关键词密度：2-3%
不要堆砌关键词
```

### 蹭热点原则

```
相关性 > 时效性
有观点 > 有信息
有干货 > 有情绪
不要硬蹭，要自然结合
```

## 九、使用技巧

### 1. 组合使用

```
# 先分析竞品
/xhs analyze @竞品账号

# 生成计划
/xhs plan 知识干货 7

# 优化某一天的内容
/xhs post 用AI做PPT

# 生成视频脚本
/xhs video 用AI做PPT

# SEO优化
/xhs seo AI做PPT

# 检查质量
/xhs check [粘贴生成的内容]

# 根据数据调整
/xhs weekly [粘贴数据]
```

### 2. 快速生成

```
# 直接说主题，省略子命令
/xhs 用AI学英语
→ 自动识别为 post 子命令
```

### 3. 迭代优化

```
# 生成初稿
/xhs post AI做PPT

# 让我修改
"标题换成更有悬念的"
"正文再口语化一点"
"加上更多emoji"
```

### 4. 一鱼多吃

```

## 十、注意事项

### ⚠️ 重要提醒

1. **不要纯AI生成不改** — 小红书能检测，会限流
2. **加入个人特色** — 生成的内容要改30%以上
3. **口语化** — 小红书用户喜欢真实感
4. **数据追踪** — 每天记录数据，用来优化
5. **互动是关键** — 每天评论同类博主
6. **养号先行** — 新号先养3-5天再发内容
7. **视频优先** — 视频流量 > 图文
8. **SEO必做** — 每篇都要优化关键词
9. **人设统一** — 不要频繁变风格
10. **循序渐进** — 变现不要伤粉丝

### 📌 内容红线

- 不要搬运他人内容
- 不要刷量（会被封号）
- 注意AI生成图片的版权
- 不要发布违规内容
- 不要频繁发广告

## 十一、常见问题

### Q: 生成的内容可以直接发吗？
A: 不建议。建议修改30%以上，加入个人风格和真实体验。

### Q: 每天发几篇比较好？
A: 新号建议每天1篇，稳定后可以每天2篇。

### Q: 什么时候能看到效果？
A: 坚持日更30天，通常第2-3周开始有明显涨粉。

### Q: 要不要买薯条推广？
A: 先不买。等有爆款内容（阅读量>平均3倍）再小额测试。

### Q: 可以同时做多个赛道吗？
A: 不建议。新号先专注一个赛道，等粉丝过万再考虑扩展。

### Q: 图文还是视频？
A: 视频流量更大，建议逐步转向视频。可以先用 `/xhs video` 生成脚本。

### Q: 怎么找竞品？
A: 搜索你的赛道关键词，找粉丝量在你目标范围内的账号，用 `/xhs analyze` 分析。

### Q: 变现要等多少粉？
A: 1000粉就可以开始接小广告，但建议先做好内容，变现水到渠成。
