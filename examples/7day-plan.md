## Day 1（周一）｜账号首篇 — 打造人设

**主题：** 自我介绍 + 价值预告

**推荐标题：** 打工人请关注我！每天一个AI工具，让你效率翻倍

**正文：**

```
👋 Hi，大家好！我是一个 AI 工具重度使用者

从今天开始，我会每天给大家分享一个
亲测好用的 AI 工具/技巧 ✨

我的内容会帮你：
📌 节省时间 — 以前2小时的事，现在5分钟
📌 提升效率 — 让 AI 做重复劳动
📌 省钱 — 免费工具为主，不推荐贵的
📌 职场加分 — 学会这些，领导都夸你

💡 我的原则：
1. 只推荐自己用过的
2. 步骤详细，小白也能跟着做
3. 免费优先，付费会提前说明
4. 不水内容，篇篇干货

🔔 明天第一期：教你用 AI 3分钟做出高颜值PPT

💬 你最想了解哪类 AI 工具？评论区告诉我

#AI工具 #效率提升 #打工人必备 #AI #办公技巧
```

**发布时间：** 18:30-19:30

## Day 2（周二）｜AI 做 PPT

**主题：** 用 AI 3分钟做出高颜值 PPT

**推荐标题：** 领导让我明天交PPT，我用AI 10分钟就搞定了

**正文：**

```
😱 昨天领导说：明天交一份PPT

以前的我：熬夜到凌晨2点，做得还很丑
现在的我：AI帮我10分钟搞定，还被夸做得好

🔧 工具：Gamma（免费）
📱 网址：gamma.app

📝 步骤：
1️⃣ 打开 gamma.app，注册登录
2️⃣ 点击「创建新演示文稿」→「AI生成」
3️⃣ 输入主题，如「Q3销售数据分析报告」
4️⃣ 选择风格，推荐「简约商务」
5️⃣ 等待30秒，PPT自动生成！
6️⃣ 微调：换logo、改数据、调颜色
7️⃣ 导出 PPT/PDF

💡 小技巧：
- 描述越详细，生成越精准
- 可上传参考图，AI模仿风格
- 免费版够用

#AI #PPT #办公技巧 #效率提升 #打工人 #Gamma
```

**发布时间：** 12:00-13:00

## Day 3（周三）｜AI 写周报

**主题：** 用 AI 5分钟写周报

**推荐标题：** 我用AI写了一个月周报，领导没发现

**万能 Prompt：**

```
请帮我写一份本周工作周报，要求：
1. 我是[你的岗位]，本周做了以下工作：[列出3-5件]
2. 用专业但不浮夸的语言
3. 突出成果和数据
4. 分为：本周完成、下周计划、需要支持
5. 字数300字左右
6. 语气积极向上
```

**发布时间：** 18:30-19:30

## Day 4（周四）｜AI 做数据图表

**主题：** 用 AI 做 Excel 数据可视化

**推荐标题：** 同事问我图表怎么做的这么好看，我偷偷用了AI

**工具推荐：**
1. ChatGPT + 代码解释器（最推荐）
2. 镝数图表（dydata.io）
3. 花瓣数据（huaban.com）

**配色公式：**
- 商务蓝：#2E86AB + #A23B72 + #F18F01
- 科技紫：#7B2FBE + #3F88C5 + #13D8AA
- 简约灰：#333333 + #666666 + #999999

**发布时间：** 12:00-13:00
